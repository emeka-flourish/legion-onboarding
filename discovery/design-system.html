Legion onboarding design reference

An observed reconstruction of Legion's patient-onboarding design language, built so a redesign can stay recognizably Legion. All content is synthetic. The header mark is a placeholder, not Legion's logo file. The companion document is discovery/design-system.md.

Legion's stack is Tailwind CSS plus shadcn/ui with Inter. The shadcn theme variables in this file's :root are copied exactly from the live site and can be pasted into a prototype's globals.css.
